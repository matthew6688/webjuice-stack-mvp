# Logo Review — Vicwest Roofing

## Brief

- Business: Vicwest Roofing
- Niche: roofing and restoration (residential + light commercial)
- Location: Ballarat, Victoria
- Tone: industrial, straightforward, trade-credible, no-nonsense
- Conversion mode: existing-logo from live site (`vicwestroofing.com.au`) — fidelity preserved, not redesigned.

## Source

Live site PNG (1773×1179, transparent, clean flat raster) was path-traced via potrace because no vector source was published. Tier-1 conversion: clean flat logo with two-tone monogram (black V + steel-gray R) and a separately-set wordmark in darker gray. No effects, gradients, or strokes to reverse-engineer.

## Asset Set (9 SVGs)

Stacked lockups (light, dark, mono-light, mono-dark), standalone mark, standalone wordmark, horizontal lockup (derived 2026-05-27), favicon, social-avatar. All viewBoxes carry export-safety padding; all paths are solid fills.

## Subjective Assessment

The VR monogram is the strongest element of this identity. The interlocking V (#000) + R (#6D6E71) creates immediate visual weight at small sizes and works as a standalone mark down to ~24px — uncommon for a two-letter monogram. The Y-junction where the V's right arm meets the R's bowl is the ownable detail: it reads as both letterforms and as a structural truss, which is on-brief for a roofing brand. The wordmark is geometric, flat-bottom, slightly extended (Eurostile / Bank Gothic family) — trade-credible without veering corporate. The two-tone treatment (black + steel-gray) avoids the gradient/badge cliché endemic to roofing logos. The brass accent (#C5A572) is reserved for the website system, not the mark itself — the right call: keeps the logo print-safe and the warm accent earns attention as a UI signal.

Weakest aspect: as a path-traced raster, curves are visually faithful but not bezier-clean. At 4× zoom you can see minor potrace artifacts on the R's inner bowl. Acceptable for screen, marginal for large-format print — flag for client-supplied vector if Vicwest ever does signage.

## Final Notes

- Fidelity preserved — no redesign was performed or warranted. Source mark is already strong; intervention would degrade brand recognition for existing customers searching `vicwest roofing`.
- If a client-supplied AI/EPS becomes available, swap path-traced SVGs for the source vectors and re-export this kit. Token values and structure remain valid.
- Don't invert the V↔R color relationship. Don't add drop shadow, outline, or gradient. Don't condense the wordmark — it must remain upright extended geometric.
