### 关键问题 · 2 项（立刻在伤害成交）

### 关键 · No visible phone call action

**技术事实**

On the desktop screenshot, the top navigation shows ABOUT US, SERVICES, PROJECTS, CAREERS, CREDIT INFO and CONTACT, but there is no phone number or quote button visible above the large roof image; on mobile, the first screen shows a hamburger icon but no tap-to-call button.

**对客户的影响**

本地搜索客户通常会快速比较多家公司，很多人会在几秒内决定打给谁。手机端没有一键拨号，会直接损失正在准备联系屋顶工的客户。

**正确长啥样**

A phone number and primary CTA should be visible without scrolling on both desktop and mobile, such as a black header with 'Call 03 xxxx xxxx' and a contrasting 'Get a Quote' button.

**Redesign 怎么改**

Add a persistent header CTA: desktop should show the phone number and 'Get a Quote' button on the right; mobile should show a sticky bottom bar with 'Call' and 'Quote' actions.

### 主要 · h1_unique

**技术事实**

0 <h1> tags

**普通话翻译**

页面要么没有 H1 标题（搜索引擎无法理解页面主旨），要么有多个 H1（搜索引擎不知道哪个是主题）。

**对客户的影响**

H1 是搜索引擎判断页面主题最权威的信号。写错或缺失 = 关键词排名拉低；同一页面同样的内容，H1 写对的可以排到前 3 页，写不对的可能挂在第 7 页。


### 主要 · local_schema_markup

**技术事实**

no LocalBusiness JSON-LD

**普通话翻译**

网站没有 LocalBusiness JSON-LD 结构化数据（让 Google / AI 知道你是本地企业、地址、电话、营业时间的标准格式）。

**对客户的影响**

Google「附近的服务」「Knowledge Panel」「AI Overview」都依赖这类结构化数据。没有 = 即使排名上去也不会出现在右侧 Knowledge Panel 或地图卡片里 — 错失高转化的展示位。AI agent / ChatGPT 引用本地商家时也是基于这些数据。
